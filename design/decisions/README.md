# Decision records

Record consequential choices with status, context, alternatives, consequences,
validation and revisit trigger. Link specifications instead of duplicating them.
Product/stack commitments need Lee; routine reversible maintenance does not.
Each record's Status line says whether and where it shipped; current behavior lives
in [product behavior](../product-behavior.md) and the other design docs. A record
is not rewritten when a later decision changes it: the later record says what it
supersedes, and the earlier one gets a one-line pointer.
