# Tandemlog

Shared household tasks for Android, Windows and Linux. Work offline and keep your devices in sync through a folder you choose.

- Capture tasks quickly, one at a time or several together.
- Organize tasks with tags, dates, times and recurring schedules.
- Assign tasks to household members, then search and filter what you need.
- View completed tasks, reopen them and undo recent task actions.

## Sync your way

Use a folder-sync tool such as Syncthing or a desktop Dropbox folder. Choose a folder that Tandemlog and your sync tool can both read and write. Each device keeps its changes in separate files, avoiding competing writes to one shared file. Tandemlog combines arriving changes; simultaneous edits to the same task can still require review.
