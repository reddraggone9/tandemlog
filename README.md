# Tandemlog

Shared household tasks and food inventory for Android, Windows and Linux. Work offline and keep your devices in sync through a folder you choose.

- Capture tasks quickly, one at a time or several together.
- Track food containers, expiration dates and locations.
- Share product details across containers and see which products are running low.
- Organize tasks with tags, dates, times and recurring schedules.
- Keep smaller steps in inline checklists with item notes and ordering.
- Edit task titles and notes collaboratively across devices.
- Assign tasks to household members, then search and filter what you need.
- View completed tasks, reopen them and undo recent task actions.

## Sync your way

Sync between devices using tools like Syncthing or Dropbox. Each device records its own changes. Tandemlog combines them as files arrive through the synced folder.

## Get started

Download the [latest stable release](https://github.com/reddraggone9/tandemlog/releases/latest) and see the [installation instructions](packaging/README.md) for platform requirements. Experimental previews are available separately on [Releases](https://github.com/reddraggone9/tandemlog/releases).

**Upgrading from 2026.10.6 or earlier:** existing workspaces need an offline, coordinated conversion before 2026.10.7 or later is opened. Keep the previous version until conversion is complete with every writing installation included, then update all writing devices. These releases cannot convert an older workspace in the app. Updating from 2026.10.7 or 2026.10.8 needs no manual conversion. 2026.10.9 introduces a one-release workspace format change: older installs stop with “Update the app” until updated.
